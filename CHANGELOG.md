# Changelog

## 1.0.0 — 2026-11-04

First release, tested on a SCALA1 (GENI family 57, type 1).

- Zero-config pairing: finds the nearest SCALA1, sends the pairing request, pairs on the blue button, remembers the pump.
- Status, alarms and warnings (with plain-English descriptions), history, dry-run and external input settings.
- Stop / auto / reset alarms.
- Blueprints: low tank cut-off, alarm notification.
